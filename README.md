## 🌐 网站定位 (Roles)

本站部署于 GitHub，旨在为不同角色的用户提供一站式服务：

* **🎮 玩家 (Players):** 查看服务器在线状态、个人数据统计、活动公告。
* **🛡️ 管理员 (Admins):** 在线执勤工具、玩家数据审计、服务器实时监控。
* **👑 服主 (Owner):** 全局配置同步、基于 Git 工作流的自动化运维。
